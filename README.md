# ブロックス（最終課題）

仕様書(`仕様書.md`)に基づいて実装した、ブラウザで動くボードゲーム「ブロックス」のWebアプリです。

## 起動方法

`index.html` をブラウザ(Chrome / Edge など)で開くだけです。

## 遊び方

1. あなたとCPU3人の対戦です。画面上部の「あなたの色」で操作する色を選べます(再スタート時に反映)。
2. あなたの手番になったら、パネルからピースをクリックして選択します。
3. ボード上にカーソルを合わせると、置ける場所は緑、置けない場所は赤でプレビュー表示されます。
4. クリックで配置します。`R` キーまたは「回転」ボタンで回転、`F` キーまたは「反転」ボタンで左右反転できます。
5. 置ける場所がない場合は「パス」を押します。
6. CPUの手番は自動で進みます(大きいピースから優先して配置)。

### ルール

- 20×20のボード上に、自分の色のピースを置いていくゲームです。
- 最初の1手は、自分の色の角(赤=左上 / 青=右上 / 緑=右下 / 黄=左下)に置きます。
- 2手目以降は、**同じ色のピースと角(斜め)で接する**ように置きます。
- **同じ色のピースと辺で接する配置は禁止**です(他色とは辺で接してもよい)。
- ピースはボードの枠内に収め、一度置いたら動かせません。
- 置ける場所がなくなったらパスします。
- 全員がパスするか、誰かが手持ちをすべて置き切ったら終了。**手持ちの残り枚数が最も少ない人が勝ち**です(同数なら残りマス総数が少ない方が上位)。
